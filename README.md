# NewsCorp × MadConnect — CDL POC Console

Single-file interactive console for the NWS-001 Connected Data Layer proof of concept
(Dow Jones + Realtor.com, targeting CES January 2027).

Grounded in real discovery artifacts: DJ Snowflake schema, Realtor GAM/clickstream
package, identity stack (VXID/News ID/Permutive/PPID/RampID/UID2, vst/puid/jy),
and the actual requirements doc (Ingest / Govern / Activate).

## Run locally
Just open `index.html` in a browser — no build step, no dependencies.

## Structure
- `index.html` — the entire console (HTML/CSS/JS, self-contained)
